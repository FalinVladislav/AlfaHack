# Отдельный сервис моделей

Опциональная интеграция, не включённая в Compose. Сервис не запускает и не загружает модели автоматически. В этой ветке подключать его для работы приложения не требуется.

Всё, что зависит от Ollama (URL, модель, формат провайдера), находится здесь. Backend знает только контракт `POST /v1/chat`:

```json
{"instructions":"Контекст и правила ответа", "message":"Сообщение пользователя"}
```

Ответ — JSON-объект с `intent`, `answer`, опциональным `proposed_fields`. Ошибка провайдера возвращает HTTP 503. Backend самостоятельно проверяет разрешённые поля и применяет предложение только после подтверждения пользователя.

При дальнейшем подключении: Python 3.10+, отдельно работающая Ollama; задайте переменные из `.env.example` в окружении и выполните `python inference/server.py` из корня. Файл `.env` автоматически не загружается. Для backend задайте `MODEL_API_URL=http://localhost:8090`. Без URL помощник сообщает о недоступности, остальные сценарии работают.

Проверка процесса: `GET /health`. `configured` означает наличие настройки модели, а не проверку её готовности.

Тесты без реальной модели: `python -m unittest discover -s inference -v` из корня.
